## 2024-05-15 - Icon Button Tooltips and Labels
**Learning:** Found multiple instances where small icon-only buttons lacked `aria-label` or `title`, which hinders screen-reader and tooltip experiences.
**Action:** Always verify `<Button size="icon" />` and `<Button size="icon-xs" />` have an accessible label or title attached when maintaining existing code in this repository.
## 2026-10-28 - Custom Tooltip Component Usage\n**Learning:** The project uses a custom `Tooltip` component (`client/src/components/tooltip.tsx`) to avoid overflow clipping issues common with standard tooltip libraries or native `title` attributes. Native `title` attributes on icon-only buttons cause accessibility redundancy if not paired with `aria-label` correctly, and their delay/style is uncontrollable.\n**Action:** Always replace native `title` attributes on icon-only buttons with the custom `<Tooltip text="...">` wrapper and ensure the underlying `<Button>` has an explicit `aria-label` for screen readers.
